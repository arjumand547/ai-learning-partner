# 🧠 AI Learning Partner (Mobile App)

A real mobile-friendly Progressive Web App for BS AI students.

## Features
- AI Tutor (logic + examples + ready prompts)
- Degree manager with per-course AI
- Attendance tracker (80% rule, color coded)
- Scholarships tracker
- Freelance hub (Fiverr / Upwork + AI advice)
- Works offline after first load
- Installable on phone & desktop

## How to deploy (GitHub Pages – free)

1. Create a new public GitHub repository
2. Upload **all files and folders** from this project
3. Go to repository **Settings → Pages**
4. Under "Source" choose **Deploy from a branch**
5. Select branch **main** and folder **/ (root)**
6. Click Save

After 1 minute your app will be live at:  
`https://yourusername.github.io/repository-name/`

## Install as mobile app
- Open the live link in Chrome on your phone
- Tap menu → **Add to Home Screen**

## First time setup
1. Open the app → Settings
2. Get free key from https://console.groq.com
3. Paste and save

All your data stays on your device.
